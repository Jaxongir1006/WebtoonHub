# 🛡 WebtoonHub Admin & Studio (Boshqaruv Paneli)

Ushbu qism Creator (komiks yuklovchilar) va Adminlar uchun maxsus boshqaruv ilovasi hisoblanadi:
* **Texnologiyalar:** Vue.js 3, Vite, Tailwind CSS, Pinia
* **Vazifalari:**
  * Xodimlar avtorizatsiyasi va sessiyalari
  * Manhvalar yaratish va bob rasmlarini to'plam qilib MinIO ga yuklash
  * Boblar moderatsiyasi (Pending -> Published / Rejected)
  * Dinamik Rollar va Ruxsatlar boshqaruvi (RBAC)
  * Do'konga yangi buyumlar qo'shish
  * Creatorlik arizalarini ko'rib chiqish va tasdiqlash
